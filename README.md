# Dostaffkin

Лёгкое одностраничное Angular-приложение для отслеживания доставки и оформления заказов.

## Кратко
- SPA на Angular с минимальной структурой: страницы `home`, `order`, `track` и компонент `header`.
- Взаимодействие с API через сервис `src/app/services/delivery-api.ts`.

## Ключевой функционал
- Отображение главной страницы (`/`).
- Создание/оформление заказа (`order`).
- Отслеживание статуса доставки (`track`).
- UI-уведомления через `ngx-toastr`.

## Технологический стек
- Язык: TypeScript
- Фреймворк: Angular 21
- Библиотеки: `rxjs`, `ngx-toastr`, `tslib`
- Сборка/CLI: `@angular/cli`
- Тесты: `vitest` (dev)

## Структура (основное)
- `src/app/` — приложение
  - `header/` — шапка
  - `pages/home/`, `pages/order/`, `pages/track/` — страницы
  - `services/delivery-api.ts` — API-клиент
- `docs/`, `public/` — артефакты сборки/статические файлы

## Установка и запуск
1. Установить зависимости:

```bash
npm ci
```

2. Запустить в режиме разработки:

```bash
npm start
# открывается на http://localhost:4200
```

3. Полезные команды (из `package.json`):
- `npm run build` — собрать приложение
- `npm run watch` — билд в режиме наблюдения
- `npm test` — запустить тесты

## Примечания
- Конфиги и дополнительные статические страницы лежат в `docs/`.
- Для изменения API — править `src/app/services/delivery-api.ts`.
